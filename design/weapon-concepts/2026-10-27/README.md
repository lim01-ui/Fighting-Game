# Pixel-art weapon design candidates

Standalone transparent PNG concepts matching the fighting game's dark pixel
outlines, compact readable shapes, limited shading ramps, and colored energy
accents. These designs are **not integrated into the game**.

## Provenance

Created with the built-in `image_gen` tool using the existing obsidian robot
concept's pixel rendering as a style reference. Exact descriptions, prompts,
and output filenames are recorded in `generation.json` beside these PNGs.
`additional-generation.json` records the nine later designs (14–22), using the
Rook/Raguel/Vex preview for pixel-rendering style.
`straight-katana-revision.json` records the straight-blade correction to item 17.

No game code, equipment assignments, attacks, damage values, sprite loaders,
or active character artwork is changed by this concept package.
